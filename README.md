# mpv Binary Search/Bisect Plugin

This plugin allows you to perform a (manual) binary search/bisect in a video. Think, CCTV footage: your bike got stolen and you have 12 hours of footage, bam bam bam a couple keypresses and you can hone down on when your bike was stolen.

[install](https://github.com/m3rone/mpv-binarysearch/releases/latest/download/binarysearch.lua): `~/.config/mpv/scripts/binarysearch.lua`

keys: `b` earlier, `n` later, `ctrl+z` undo
